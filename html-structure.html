Aspect 1: HTML5 Structure

The Document Skeleton

The head of the template declares UTF-8 and a viewport meta tag, and links one external stylesheet, w3.css version 6. The source shown in the Try-it editor starts with the html tag, so it has no DOCTYPE, no lang attribute, and a generic title ("W3.CSS Template").

Headings and the Contact Form

  • The page has one h1, three h2 headings, and four h3 headings (team members); no level is skipped.
  • All four form fields are required, so the browser validates the form without JavaScript.
  • The inputs use placeholders instead of label elements, and the comment field is a single-line input instead of a textarea.

Proposed Improvement

<label for="email">Email</label>
<input id="email" type="email" name="Email" autocomplete="email" required>

Lesson: a utility-class framework controls appearance only; meaning is still the author's job.
