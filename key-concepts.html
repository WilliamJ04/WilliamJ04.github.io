Key Concepts

1. Semantic HTML

Using elements such as header, nav, main, and footer to describe the meaning of content, which helps assistive technology and search engines.

2. Utility Classes

Small single-purpose classes, such as w3-padding, that are stacked on an element to build its look.

3. Flexbox

A one-dimensional layout system, used in the template for the navigation bar.

4. CSS Grid

A two-dimensional layout system, used for the project and team galleries.

5. Specificity and the Cascade

The rules that decide which declaration wins when several apply, including the effect of !important and inline styles.

6. Responsive and Accessible Design

Layouts that adapt to any screen width, and pages that remain usable with a keyboard or screen reader. Hiding content is not free.
